# TypeScript `tsconfig.json` — Practical 7: `target: "ESNext"`

## Goal

Understand how `target` affects the JavaScript generated by the TypeScript compiler.

## Step 1: What Does `target` Do?

The `target` option specifies the ECMAScript version TypeScript should target when generating JavaScript.

For example, TypeScript code:

```
const username: string = "Amit";

console.log(username);
```

Generated JavaScript:

```
const username = "Amit";

console.log(username);
```

The TypeScript type annotation is removed because JavaScript does not support TypeScript type annotations.

## Step 2: Configure `ESNext`

Update `tsconfig.json`:

```
{
  "compilerOptions": {
    "rootDir": "./src",
    "outDir": "./dist",
    "module": "NodeNext",
    "target": "ESNext"
  },
  "include": ["src/**/*.ts"],
  "exclude": ["node_modules", "dist"]
}
```

Update `src/index.ts`:

```
const username: string = "Amit";

const user = {
  username,
  greet() {
    return `Hello, ${this.username}!`;
  }
};

console.log(user.greet());
```

## Step 3: Compile and Run

Execute:

```
npx tsc
node dist/index.js
```

Expected output:

```
Hello, Amit!
```

## Step 4: Inspect the Generated JavaScript

Run:

```
cat dist/index.js
```

Expected output:

```
const username = "Amit";
const user = {
    username,
    greet() {
        return `Hello, ${this.username}!`;
    }
};
console.log(user.greet());
```

Formatting may vary slightly depending on the TypeScript version.

Notice that:

- TypeScript annotations are removed.
- `const` is preserved.
- Template literals are preserved.
- Method shorthand is preserved.

## Step 5: Understand `ESNext` vs. `ES2020`

- `ES2020` targets the ECMAScript 2020 language feature set.
- `ESNext` targets the latest ECMAScript features supported by your installed TypeScript compiler.

Some newer JavaScript features may be transformed differently depending on the target. TypeScript does not guarantee that every unsupported feature will be converted into older JavaScript.

**Important:** `target` does not add missing JavaScript features to your Node.js runtime. Your runtime must support the generated code.

## Step 6: Practical Experiment

Change the target in `tsconfig.json`:

```
"target": "ES2020"
```

Compile and run again:

```
npx tsc
node dist/index.js
cat dist/index.js
```

Compare the generated JavaScript with the `ESNext` version. For this particular example, the output may look almost identical because the syntax is supported by both targets.

Restore `"target": "ESNext"` after the experiment.

## Best Practice

Choose a target compatible with your production Node.js version.

- `ESNext` is convenient when you want the latest supported JavaScript syntax.
- A fixed target can make builds more predictable across environments.
- Always verify runtime compatibility before deploying.

## Key Takeaways

- `target` controls JavaScript language compatibility.
- TypeScript types are removed during compilation.
- `ESNext` preserves modern syntax when possible.
- The target does not polyfill missing runtime features.
